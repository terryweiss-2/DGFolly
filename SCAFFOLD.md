# DGFolly

DGFolly is a proof of concept for a web site that can perform a couple basic mental measurements. The site is not
intended for general use, nonetheless it needs to be secure. It will not capture any personal information, it does not
contemplate user accounts. It will consist of a single page (SPA) that is served from a simple web server.

## Implementation

- Create this as a monorepo. See [AGENTS.md](AGENTS.md) section `Layout`
- Call this `DGFolly` and create an appropriate `package.json` in each package with `type: module`. And with the technologies specified
  in AGENTS.md
- npm install
- Don't implement any features or libraries, just provide stub `index.js` files.
